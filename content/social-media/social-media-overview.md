# Social Media Templates — Overview

Each social template in this folder is a **skill**. A skill is a document that tells the AI how something should look — here, that means the size, layout, colours and type of a post graphic. In this folder, "skill" and "social template" mean the same thing.

## 1. Pick the size

Every platform crops differently, so the canvas is the first decision.

| Template | Size | Where it goes | Example |
|---|---|---|---|

## 2. Ask for your graphic

```text
Make a LinkedIn post using the `linkedin-post` skill.

The point: we cut report turnaround from four hours to twenty minutes.
Lead with the number. One line of context underneath.
```

Name the skill exactly as it is written on its entry. Give it **one** point to make — that is the whole discipline of the format.

Name your brand skill alongside it ([[your-brand-overview]]) and it comes out in your colours and type.

## 3. Adjust

Ask by part: *"make the number bigger"*, *"swap the quote for the stat version"*, *"give me the story version of this too."*

## What makes these work

Social is not a small poster. Three things are different, and every template here is built around them:

- **It is seen all at once.** There is no fold and no scrolling — every element competes for attention immediately. One idea per graphic.
- **It is first seen small.** A feed thumbnail is a fraction of full size, and a YouTube thumbnail is often about 168px wide. If the headline does not survive that, nothing else matters. Each template states its word budget.
- **Platform chrome covers the edges.** Stories in particular put interface elements over the top and bottom of the canvas — the story template reserves those bands so nothing important lands underneath.

Sizes change. If a platform has moved since these were written, say so in your request and ask for the canvas you need — the layout adapts.
